## 1. 参考视频到底在动什么

屏内不是「三张海报切换」，而是：

| 层 | 参考里的行为 |
|----|----------------|
| **世界层** | 连续空间被 scroll 打开（山/海 → 洋面） |
| **主体层** | 货轮/游轮在画面里有**持续位移 + 尾迹** |
| **文案层** | 大标题/信息卡钉在稳定构图上，随章节换内容 |
| **微动层** | 海浪、尾迹泡沫、光斑——证明「世界活着」 |
| **交互暗示** | SCROLL、圆形控件——像真网页 |

**最后几帧的游轮** = 冻结主构图后，**主体仍在缓慢航行 + 白色航迹**。  
这给观众「页面停住了，世界没死」。

## 2. 映射到我们的香港一镜

| 参考 | 我们（中环日间） |
|------|------------------|
| 远景自然开场 | H1 天空 / 楼缝仰天 |
| 中景品牌钉住 | H2 峡谷 + `Metal AI OS` |
| 近景叙事世界 | H3 街道冻结 |
| **游轮缓慢前行 + 尾迹** | **车流微移 + 尾灯/头灯呼吸 + 车光拖尾** |
| 海浪闪动 | 玻璃橱窗扫光、路面高光轻微呼吸 |
| 航迹泡沫 | 车道上极淡的「运动残影」条带（克制） |
| 全屏大字节点 | Slide 文案钉在 street 稳定点（C3） |
| 信息卡贴在运动主体旁 | 经营信号卡贴在询盘/报价节点（后阶段） |

原则：

- **一镜主运动**：相机下沉（sky→city→street）用关键帧 + 短桥接。  
- **冻结后生命力**：街景「定住」后，用 **主体微动 + 光效** 代替整帧重渲。  
- **PPT 段**：不换世界；同一街景舞台 + 内容节点（B1）。

## 3. 可借鉴动效清单（补充完整）

### A. 相机 / 一镜（必须）

1. **下沉推进** sky→city→street（主轴）  
2. **微推近**（scale 1.03→1.08 级，忌猛 digi-zoom）  
3. **横移上限 2–3%**  
4. **短重叠 crossfade**（防双影）  
5. **可选 L2**：city→street **1–1.5s 短视频桥**（非整页 MP4 底）

### B. 冻结街景后的「活世界」（对标游轮）

| # | 效果 | 参考对应 | 香港落点 | 实现建议 |
|---|------|----------|----------|----------|
| B1 | **尾灯呼吸** | 船灯/尾迹高光 | 的士/私家车尾 | CSS glow pulse（已有，加强密度） |
| B2 | **头灯扫过** | 船体高光移动 | 对向车白/暖灯 | 小光斑沿车道短位移 |
| B3 | **车体微位移** | 游轮平移 | 近景车辆 2–6px 循环 | transform 极慢 loop；或短视频层 |
| B4 | **车道运动残影** | 白色航迹 | 车道细线高光漂移 | 半透明条带沿透视消失点 |
| B5 | **巴士/电车缓移** | 船体前进感 | 红色巴士一层 | 独立 PNG 层或短视频 |
| B6 | **行人软虚影** | 海面动态 | 人行道轻微 opacity 闪 | 极克制，防脏 |
| B7 | **交通灯状态** | 点状信号 | 灯组红/绿慢闪 | 色点 pulse |
| B8 | **广告屏轮播感** | 屏内 UI 活 | 灯箱亮度起伏 | adPulse（已有） |
| B9 | **橱窗玻璃扫光** | 海面反光 | 玻璃幕墙 | glassSweep（已有，可加 2 条） |
| B10 | **路面湿反射呼吸** | 海浪明暗 | 沥青高光 | 大面积极淡 brightness 2–3% |
| B11 | **树影/遮阳轻微晃** | 自然噪动 | 行道树 | 可选，低优先级 |
| B12 | **经营信号粒子** | UI 标注点 | 询盘/风险点 | 琥珀/青点，后阶段接业务 |

### C. 文案与 UI 节点（对标信息卡）

| # | 效果 | 说明 |
|---|------|------|
| C1 | 标题「钉住」fade | 非飞入 |
| C2 | 副文递进 | chatbot 句在 street freeze 后 |
| C3 | 信息卡从环境浮出 | 后阶段：缺资料/风险/行动 |
| C4 | scroll hint 呼吸 | 参考 SCROLL DOWN |
| C5 | 进度非工程化 | 用经营链路点，而非 S01 标签 |

### D. 音频（可选，默认关）

- 极低城市底噪 / 无声  
- 不要强 BGM 盖过演示讲解  

### E. 禁止（会毁一镜）

- 全页长视频当背景导致字不可读  
- 大横移换景  
- 夜景皮肤突然插入  
- 每页换无关照片  
- 过密粒子像屏保

## 4. 推荐技术架构（真接近参考）

```text
┌─────────────────────────────────────┐
│  Content Track（PPT 文案 DOM）        │  slides.js 零改字
├─────────────────────────────────────┤
│  Ambient / Subject Motion 层         │  尾灯、扫光、车微移、信号点
├─────────────────────────────────────┤
│  Bridge（可选）city→street 短视频     │  1–1.5s，只播一次或 scrub
├─────────────────────────────────────┤
│  Keyframe stills H1 H2 H3（同轴）     │  H2 锚 → edit 出 H1/H3
└─────────────────────────────────────┘
```

### 阶段

| 阶段 | 交付 | 接近度 |
|------|------|--------|
| **P0 现况** | 同轴三帧 + fade + 基础 ambient | 演示可用 |
| **P1 活街景** | 补全 B1–B10 光效密度 + 车道残影 | 明显「活」 |
| **P2 真桥接** | 生成/拍摄 H2→H3 短视频桥，scroll 绑进度 | **接近参考** |
| **P3 主体层** | 巴士/的士独立层慢移（对标游轮） | 很接近 |
| **P4** | 2.5D 分景 mask 视差 | 产品页满级 |

**销售优先建议：做完 P1 + P2。**  
游轮 = 我们的「的士/巴士主体层」，不是真去画海。

## 5. 短视频桥（P2）怎么做才不像「视频背景站」

1. 只做 **city 锁标题后 → street 冻结前** 的 1–1.5s。  
2. 画面必须从 H2 构图过渡到 H3 构图（同轴）。  
3. 页面默认仍是 stills；桥接仅在该 scroll 区间 `opacity` 起来。  
4. 文案层始终在 DOM 最上，视频不烧字。  
5. `prefers-reduced-motion`：跳过视频，硬切 stills。

## 6. 验收（比感觉更硬）

**一镜**

- [ ] 三帧并排：同一街轴、同一日照  
- [ ] 盲测能说出「在往下进香港街」  
- [ ] 叠化无重影  

**活世界（对标游轮）**

- [ ] street freeze 后 3 秒内能察觉 ≥3 种微动（灯/光/残影）  
- [ ] 微动不抢标题可读性  
- [ ] B 段 PPT 仍在同一街景舞台  

**参考对齐**

- [ ] 有「主体持续运动」等价物（车/光迹，不是只有静态图）  
- [ ] 有「文案钉在运动世界上」  
- [ ] 无电脑外壳叙事
