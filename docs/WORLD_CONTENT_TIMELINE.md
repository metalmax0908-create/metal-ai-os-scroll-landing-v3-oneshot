# World track + Content track

Scroll progress `p` maps 0→1 across the full deck. Hero consumes early scroll; PPT continues after.

| Scroll (approx) | World track | Content track (PPT, zero text change) | Feel |
|-----------------|-------------|----------------------------------------|------|
| 0–15% | Sky dominant; tower tops enter bottom | Brand micro only | Page opens |
| 15–40% | City cluster / harbour canyon push | Slide 1 title + subtitle lock | Hong Kong OS |
| 40–55% | Street eye-level freeze + ambient | Slide 1 body + Slide 2 anti-chatbot | Not a chatbot |
| 55–100% | **B1**: same daylight street stage, lower contrast / slight hold | Slides 3–32 in order | Same site, read story |

## Camera rules

- Primary: down + gentle push-in
- Lateral ≤ 2–3% frame
- Far slow / near faster parallax
- No Dutch angle; stable horizon
- Daylight only on default path

## Text rules

- No text baked into hero images
- DOM overlays pin at camera settle points
- No public engineering labels (debug only)
